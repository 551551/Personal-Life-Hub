- 页面启用沙箱、上下文隔离和 Web 安全，禁用 Node.js，拒绝权限、外部导航、新窗口与外网请求。

## Android 手机版补充验收

- Capacitor Android 原生工程已生成，应用 ID 固定为 `com.personallifehub.app`，最低支持 Android 7（API 24）。
- 手机端采用五入口底部导航，其余模块收纳到“更多功能”底部面板；八个业务模块全部可达。
- 375 × 812 视口通过无页面级横向滚动、底部安全区和不小于 44px 的可见表单控件验收。
- Android 返回键在业务页返回上一页，在首页最小化 APP；备份导出接入系统分享面板。
- Android 不申请联网权限，禁止系统云备份、混合内容和生产 WebView 调试。
- `pnpm verify:mobile` 作为移动版完整质量门禁；生成 APK 还需要本机 Android Studio 与 SDK 环境。
