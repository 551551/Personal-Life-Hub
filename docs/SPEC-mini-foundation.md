# mini-foundation：工程与本地存储规格（待审阅）

## 目标

让 AppID `wx3e05a9b25530c50a` 对应的独立工程可编译，并完成备忘创建、保存和重启读取闭环。其余功能在此可靠基础上扩展。

## 命令、结构与风格

遵循 `../tasks/plan.md` 的命令契约、`wechat/` 目录和 TypeScript 约定。新增模块用可注入的平台接口测试，不把全局 `wx` 绑定到公共纯逻辑。

## 接口边界

提供快照读取、验证后提交与查询接口，页面不直接修改存储对象。提交 Promise 成功才代表已保存；失败不改变内存已提交版本。备份版本和微信 AppID 分离。并发写入必须串行或明确冲突检测，不静默覆盖。

## 测试与成功标准

- 配置 AppID、入口、资源路径检查通过，产物没有 Dexie/React DOM/Capacitor 依赖。
- 空存储初始化、重启读取、损坏检测、容量不足、提交中断和并发写入测试通过。
- 备忘增改删验证通过，手机关闭重开后已保存记录仍在。

## 不做与前置核验

不改变网页数据库，不引入联网持久化。官方 SDK 和存储上限须核实后记录；模拟平台测试不能证明真机持久化。
