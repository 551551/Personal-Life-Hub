# mini-overview：首页与今日规格（待审阅）

## 目标

让首页与今日计划使用同一份业务记录，不复制出独立任务副本，避免完成状态不一致。

## 命令、结构与风格

遵循 `../tasks/plan.md`。计划适配源放在 `wechat/core/`，首页、今日和更多页面分别维护；优先复用已有纯逻辑而非浏览器路由。

## 接口与依赖

依赖 mini-foundation、mini-records。来源键保留 `sourceType:sourceId`；日期查询、完成和改期指向原始记录；路由转换为小程序页面导航，不携带整条个人记录到分享路径。

## 验收与测试

- 今日按未完成/完成、优先级、时间及标题排序，与现有注册表一致。
- 完成与改期后原模块、今日和首页一致；非法来源报错，删除后不残留计划。
- 首页展示今日摘要、快速备忘、模块数量及重要日期；更多页保证八模块可达。
- 测试覆盖多来源同 ID、跨日、空数据、排序和状态回写，真机核验列表到详情导航。

## 边界

不新增通知订阅、云端日历或自动同步。平台不支持的排序或路由能力必须明确适配并测试。
