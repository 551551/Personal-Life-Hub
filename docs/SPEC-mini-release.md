# mini-release：验证与发布规格（待审阅）

## 目标

提供可复核的开发者工具工程、验证记录与用户操作说明，并区分本地完成、预览、审核、正式发布状态。

## 命令、结构与风格

遵循 `../tasks/plan.md` 中 `verify:wechat` 与原有回归命令契约。产物仅来自经测试的工程版本，测试报告与说明放在 `docs/`，不把密钥或私人文件写入报告。

## 依赖与上线边界

依赖其余四模块完成。先做自动化与产物体积核验，再开发者工具编译、管理员真机测试，最后核对备案/隐私/类目与提交材料。以后台实际要求为准，不承诺审核通过。

## 成功标准

- 自动化测试、共享功能回归、工具编译、真机八模块与备份测试均有独立结果。
- 用户本人完成需要的账号权限、扫码和实名步骤；不索取 AppSecret。
- 上传、审核和发布有真实状态，正式上线前报告任何未完成条件。
- 保留原网站和 APK，回退不删除用户数据；发布前提醒导出备份。

## 不做

不伪造备案、认证或隐私声明，不调整类目规避审核，不关闭平台校验来冒充正式可用，不在未核验的情况下声称已上线。
