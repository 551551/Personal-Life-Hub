## 已实现的主流程

| 模块 | 可用内容 |
|---|---|
| 首页 | 今日数量和待完成摘要、快速备忘入口、业务数量、八模块导航 |
| 今日计划 | 临时任务、九类来源按日期自动汇总、优先级排序、完成和改期回写来源 |
| 自媒体 | 内容、平台、制作阶段、计划/实际发布日期、指标及复盘、编辑和删除 |
| 科研 | 项目、里程碑、文献及阅读笔记、实验计划/过程/结果/下一步、论文及章节/修改项 |
| 训练 | 训练计划、日期、动作、组数/次数/时长/重量及排序，不采集身体指标 |
| 饮食 | 餐次、食物、数量、单位、营养值、按日营养汇总 |
| 娱乐与吉他 | 游戏/视频/电影等记录、进度、计划日期、曲目与练习计划/时长/重点 |
| 数据与设置 | 全部 17 表 JSON 导出及恢复、格式/大小/引用校验、取消与失败保护、清空二次确认 |

快速备忘支持新增、编辑、确认删除、分页。本地数据没有云同步。清理微信数据、更换设备或卸载微信可能失去记录，请保留独立备份。

为优先实现全部主模块，文献、实验、论文、训练动作、饮食等使用共享原生表单组件，各自保留独立业务字段、校验、关联和汇总逻辑，不是同一个待办列表改名。复杂筛选、图表、批量操作及视觉精修属于后续优化，未伪装成已完成。

## 未通过或不能替代的验收

1. 原生控件 Page/Element 自动点击测试在当前开发者工具/自动化 SDK 组合中超时；部分导航回调报 timeout，但页面实际已进入且处理器可工作。保留失败脚本，处理器测试不等同于真实点击通过。
2. 一次保存后立即关闭开发者工具的测试，重启未见新备忘；后续确认存储中已写入、间隔操作后关闭，重启读取/编辑/删除通过。原因尚不能确认为产品或模拟器落盘行为。必须在手机上验证立即退出、正常退出及重开，未排除前不能宣称数据可靠性完整验收。
3. 尚未使用真实 Android/iOS 手机验证所有输入控件、中文键盘、文件发送、聊天文件选择及完整备份恢复。原生文件系统读写通过不能替代手机分享/选择界面验证。
4. 后台基础信息、备案、隐私保护指引、类目适配的当前状态尚未获得管理员页面证据；已批准“工具 > 备忘录”类目不代表程序审核通过。
5. 官方 CLI 只完成开发版上传。未提交审核、未获得审核通过、未发布线上版。

## 管理员下一步与手机验收

登录微信公众平台核对开发版本 `1.2.0`，将它设置为体验版并用管理员微信扫码。不要提供账号密码、AppSecret、身份证或验证码给助手。

请先只用测试数据执行：

1. 打开八个模块，确认文字、按钮、输入、滚动与返回均正常。
2. 新增一条备忘并马上退出重开；另建一条稍后正常退出重开；编辑、取消删除、确认删除。
3. 建科研项目，添加里程碑/文献/实验/论文/章节，检查所属关系；训练计划添加动作，娱乐添加曲目及练习。
4. 设置今日日期，在今日页完成及改期；返回来源检查状态/日期已同步。
5. 录入两条饮食，核对当天营养合计。
6. 导出测试备份，发送到自己的文件传输助手；在聊天文件中重新选择导入，确认数据恢复；取消导入应保持原数据。用网页端导入这份测试备份核对字段（不要覆盖唯一重要数据）。
7. 仅在全部是测试数据时验证二次确认清空；取消任何一次都应保留数据。

遇到报错，请提供页面截图和步骤，不提供私人备忘或完整私人备份。确认这些检查后再核对后台所要求的备案/隐私/类目资料，提交审核，收到通过结果后发布。

平台审核与发布步骤参考 [微信官方接入指南](https://developers.weixin.qq.com/miniprogram/introduction/)；以管理员后台当前提示为准，不承诺审核结果或时长。

## 重复验证命令

在项目根目录运行：

```powershell
node scripts/verify-wechat.mjs
node node_modules/vitest/vitest.mjs run
node node_modules/typescript/bin/tsc -b --pretty false
node node_modules/oxlint/bin/oxlint .
pnpm.cmd audit --json
node scripts/wechat-main-modules-smoke.cjs
node scripts/wechat-file-smoke.cjs
```

最后两个需要已开启官方开发者工具自动化端口 9430；只操作合成测试数据。失败必须保留并分析，不能作为全绿结果。`wechat-simulator-smoke.cjs` 的 seed/verify 两阶段需在真正退出并重启工具之间执行，使用唯一测试标记。
