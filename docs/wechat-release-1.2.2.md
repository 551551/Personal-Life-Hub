# 微信小程序 1.2.2 更新记录

官方 CLI 返回 `√ upload`：**1.2.2 开发版本上传成功**，包大小 213308 字节（208.3 KB）。未提交审核或正式发布。

## 用户验收状态

记录保留：用户此前确认成功。备份手机导出/恢复：用户本轮明确回复“还未测试，我稍后验证”，仍为待验收，不将“同意继续”作为成功结果。

## 本轮修复

- 从旧链接打开已删除的记录时，保留编辑目标编号，显示不存在提示，不再静默转为新增。
- 点击已失效的编辑按钮时清除旧编辑表单，避免后续保存误写之前编辑的另一条记录。
- 空编辑表单不能保存；用户明确取消编辑后可重新新增，并清除旧错误提示。
- 存储格式、备份结构与权限均未变化，未触碰 Android/网页或真实业务数据。

## 测试与复核

采用测试先行：两个复现测试在修复前失败、修复后通过。初始一个夹具漏填必填状态及优先级，先修正夹具后再次确认真实错误，不将无效夹具失败作为产品缺陷证据。

- 小程序独立测试：15 文件、79 项通过。
- 全仓库：33 文件、120 项通过。
- TypeScript、oxlint 入口、隔离产物与官方 WXML 编译通过。
- `scripts/wechat-stale-edit-smoke.cjs`：原生页面拒绝无效编辑保存，明确取消后恢复新增，未生成业务记录。首次固定延迟导航检查过早失败，改为有上限的页面状态等待，保留相同 route/id 断言后通过。
- 复核确认保护发生于编辑目标选择与保存两处，存储层原有“目标不存在则拒绝”保护继续保留。
